# ToolPilot

ToolPilot is a small-business software guidance site. It helps visitors start with a business goal, compare tools at a high level, and follow official provider links for current pricing and terms.

## Site

- Home: choose a goal such as customer management, ecommerce, marketing, or design.
- Guides: practical articles about choosing software.
- About & Disclosure: explains the site's purpose and affiliate disclosure.

## Monetization

ToolPilot is being prepared for affiliate marketing. Provider links are kept as normal official links until an affiliate relationship is approved and tracked links are available.

Current monetization target:
- HubSpot Affiliate Program via Impact. HubSpot says its affiliate program is free to join, has no minimum sales requirement, and accepts content creators, software reviewers, online educators, and other content targeting business professionals.

## Development

Frontend: static HTML/CSS/JavaScript
Hosting: Vercel
Source: GitHub

The repository still contains legacy SmartMeal files and API code from the original project, but the public homepage has been rebuilt around ToolPilot.

## Disclosure

Some links may become affiliate links. If a visitor buys through an affiliate link, ToolPilot may earn a commission at no extra cost to the visitor. Recommendations should be based on fit and clearly disclosed.
