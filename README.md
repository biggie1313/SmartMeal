# SmartMeal Commercial MVP

Open `index.html` to run the prototype locally.

## Product
SmartMeal is a subscription meal-planning product designed around a clear pain point:
busy households spend too much time deciding what to cook, shopping for disconnected ingredients, and wasting unused food.

## Included
- Commercial-style landing page
- Free planner
- Household size, budget and dietary preferences
- 7-day meal generation
- Grocery checklist
- Free/Premium/Family pricing
- Premium conversion prompts
- Responsive mobile layout

## Recommended production stack
Frontend: Next.js + Tailwind
Auth/database: Supabase
Payments: Stripe
AI meal generation: OpenAI API
Nutrition: USDA FoodData Central or another licensed nutrition provider
Grocery pricing: retailer APIs/affiliate feeds where permitted

## Important
This is a front-end MVP. Accounts, real payments, AI API calls and live retailer pricing are not connected yet. Do not represent the demo pricing or grocery estimates as live data.
